zen-vcache-ai

Practical 3D V-Cache (AMD Ryzen X3D) acceleration, reproducible benchmarks, AVX-512 kernels, and llama.cpp MoE tuning for local AI on 8 GB VRAM GPUs.

Quickstart

git clone https://github.com/simonezpx3/zen-vcache-ai.git
cd zen-vcache-ai
make -C kernels
GGML_MOE_NTA=1 ./bin/vcache-run -c 2-7 -- llama-server -m model.gguf -ngl 99 -cmoe --moe-cache-mib 4096 -t 6
